# Philosophy

The paper loop tests whether ranking early movers, entering promptly, following with broker-held protection and re-entering or rotating works. It claims no measured merit before evidence. This scope carries Sextant's owner-directed trade path, recorded in [the design](../design.md) and [ADR-0001](../adr/0001-sextant-foundation.md).

Build on the official engine, broker SDK and display surface. A candidate repository supplies no authority until a clean end-to-end run and evaluation. Each new package names its upstream in [landscape](../landscape.md).

Keep operating rules short and mechanisms inspectable. CI tests the harness and citations; AGENTS.md's real-paper exact-SHA review governs account starts. Measure outcomes, keep negative evidence and turn lessons into sourced changes through PRs. Every practice has one home, with links from the other pages.
