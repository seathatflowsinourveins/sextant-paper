# Practices

Use the official upstream's shipped piece and record its pin, file:line or docs page/read date and verdict. [Landscape](../landscape.md) holds package integrations; [manifest](../manifest.md) holds the harness practices. This follows the template's never-self-invent rule and sextant-movers' package-coverage test at the commits named there.

Rank, enter with a plain LIMIT, protect with broker-held following protection, sell on a persistent breach, then re-enter or rotate. [Design](../design.md) bounds the paper loop; TradingView is display only. AGENTS.md is the single home of the hard lines and real-paper exact-SHA review rule.

Each tunable has a source and calibration state. Missing authority stays unavailable; fixtures do not provide defaults. Changes happen between sessions; nightly tuning only proposes. Trial history remains cumulative and tiers separate; the ledger writer is outside this repository.

Land through squash auto-merge on ci. Run tests before claiming success, including a failing witness before new behavior. Use fixture environments for harness subprocesses rather than inheriting service wrappers. Source: the template's `tests/repo/test_pr_check.py` and [delivery lifecycle](lifecycle.md).

A cap has one source. The source-line placeholder is read only from `SOURCE_LINE_CAP` in tests/repo/test_budgets.py; it changes after the measured import closure, not from an invented estimate. Remove unused automation and its obsolete proofs in the same change; the [adaptation lesson](lifecycle.md#adaptation-lesson-2026-11-11) explains the retained profile snapshot.
